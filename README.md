# Projects

This repository contains a collection of small front-end web projects built with HTML, CSS, and JavaScript. Each folder is an independent mini-project focused on a different web development concept, such as forms, layout design, calendars, quizzes, games, and responsive pages.

## Included projects

- `Formulario-css` — A styled HTML form using CSS.
- `calendario_2016_html_css` — A calendar layout created with HTML and CSS.
- `cuestionario_JS` — A JavaScript quiz application.
- `game_ahorcado_JS` — A hangman game built with JavaScript.
- `my_first_web_html_css` — A simple personal or landing page built with HTML/CSS.
- `number_game_JS` — A number guessing game implemented in JavaScript.
- `responsive_html_css` — A responsive web page design demo.
- `web_colegio_html_css` — A school-themed website built with HTML and CSS.

## Tech stack

- HTML
- CSS
- JavaScript

## How to use

1. Clone the repository:
   ```bash
   git clone https://github.com/irontekle-khvichia/Projects.git
   ```
2. Open any project folder in a browser.
3. If the project uses JavaScript, you can usually run it directly in the browser without any additional setup.

## Notes

This repository is intended as a portfolio of frontend practice and learning exercises. It showcases simple, self-contained web interfaces and interactive mini-applications.
